- (event) Fast path, spine only; readers: builder and IBE160 grader. Inputs: PRD (updated 2026-11-15), UX spines ux-G65-ibrahim-2026-11-15 and their memlogs. architecture/technology.md excluded by user instruction (unrelated project).
- (constraint) Stack fixed by user: Streamlit UI + Google Gemini API (free tier). Single user, no accounts, no persistence (PRD §5).
- (decision) Paradigm: functional core, imperative shell. app.py is the only Streamlit shell; core modules are plain Python with no streamlit import. Prevents UI logic leaking into testable code and lets pytest run without Streamlit or network. Rationale: beginner can test and explain core; PRD §10 automated tests.
- (decision) One Gemini request per Generate returns one StudyPack JSON (summary + quiz), validated with a Pydantic model passed as response_schema. Resolves PRD OQ 2 in line with PRD §9 assumption and UX. Rationale: halves free-tier request use; one failure path.
- (decision) StudyPack schema defined once in models.py: summary {title, sections[{heading, bullets[]}]}, quiz list (min 5) of {question, options exactly 4, correct_index 0-3, explanation}. Live and demo output both validate through it. Word count is computed by the app (whitespace split over rendered summary text), never trusted from the model.
- (decision) Single Gemini gateway: only llm.py builds genai.Client and calls generate_content; model id and key come from config.py. No automatic retry on bad response or 429; the user presses Generate again (matches UX states, saves quota).
- (decision) Typed error hierarchy in errors.py (StudyBuddyError base). Core raises only these, translating pypdf and google.genai errors.APIError (code 429 -> RateLimited). app.py maps each type to exactly one UX message from EXPERIENCE.md State Patterns; UI never catches raw library exceptions.
- (decision) Input validated in ingest.py before any API call: empty paste, 0-byte file, non-PDF, no extractable text (pypdf). ingest returns plain str; llm never receives empty text.
- (decision) Session state owned by app.py with a fixed key set: study_pack, is_demo, input_fingerprint, quiz_answers, quiz_checked. Only the Generate handler writes study_pack/is_demo/input_fingerprint; quiz widgets write only quiz keys. Stale-results note compares current fingerprint (hash of source text + length + language + demo flag) to stored one.
- (decision) Prompts are versioned text files in prompts/ (system + user template), filled with length word range and output language; schema is NOT restated in the prompt (SDK guidance). Every prompt change logged in PROMPTS.md (resolves PRD §9 NOTE FOR PM).
- (decision) Config: config.py is the only reader of secrets/env. GEMINI_API_KEY from st.secrets (Community Cloud) or .env via python-dotenv (local); MOCK_MODE env sets demo toggle default; GEMINI_MODEL env overrides model id. Key passed explicitly to genai.Client, never logged or displayed.
- (decision) Demo mode: demo.py loads demo/study_pack.json through the StudyPack model; Generate in demo skips ingest and llm entirely; is_demo drives the UX banner.
- (decision) Tests never call live Gemini: core functions take text/StudyPack in and out; llm.generate_study_pack is monkeypatched or the demo fixture used. Sample inputs in test_data/ (PRD §6.1).
- (decision) Deployment: local 'streamlit run app.py' and Streamlit Community Cloud from GitHub main; requirements.txt with == pins (Community Cloud reads it); secrets in Cloud dashboard; select Python 3.13 in Advanced settings. No CI, no logging infra: errors go to Streamlit console logs.
- (version) Verified on PyPI 2026-11-16: streamlit 1.67.0 (py>=3.11), google-genai 3.3.0 (py>=3.11), pypdf 7.1.0, pydantic 2.14.3, python-dotenv 1.2.4, pytest 9.2.0. Python 3.13 (uv-managed locally; Community Cloud supports security-maintained versions, default 3.12).
- (version) Model gemini-3.5-flash-lite: stable, on free tier, Google's recommended pick for new projects (aistudio.google.com/docs/models and /docs/pricing, 2026-11-16). gemini-2.5-flash deprecated, rerouted 2026-12-01. Free-tier data is used to improve Google products -> README disclosure.
- (assumption) Python 3.13 chosen over 3.14 for library wheel maturity; revisit if a dependency drops 3.13.
- (question) Deferred: word-range miss note and pasted-text length cap (PRD feedback 4.1/4.5) not in PRD or UX; revisit if real material exceeds model input or summaries miss ranges in testing.
- (decision) config.load_settings(secrets) takes st.secrets as a plain mapping from app.py, so config.py has no streamlit import and AD-1 has no exception. llm.generate_study_pack takes Settings explicitly; missing key raises MissingApiKey before any call.
- (decision) quiz_answers shape fixed: list[int | None] in quiz order.
